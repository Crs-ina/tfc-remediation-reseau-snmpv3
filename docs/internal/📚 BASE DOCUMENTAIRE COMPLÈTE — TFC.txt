📂 2. SOURCES CLASSÉES PAR CATÉGORIES

🏛️ CATÉGORIE A — ÉTAT DE L'ART & FONDEMENTS THÉORIQUES

[A1] RFC 3410 — Introduction to Internet-Standard Management Framework

Type : Norme IETF
Auteurs : Case, Mundy, Partain, Stewart (IETF SNMPv3 Working Group)
Année : 2002
Lien : https://datatracker.ietf.org/doc/html/rfc3410
Résumé : Ce document constitue le point d'entrée officiel de la suite SNMPv3. Il explique pourquoi l'utilisation de SNMPv3 est fortement recommandée à la place de SNMPv1 ou SNMPv2, et introduit l'ensemble de l'architecture modulaire du framework de gestion de réseau. IETF
Utilité TFC : Référence fondamentale pour justifier le choix de SNMPv3 dans le Chapitre I. À citer en premier dans ta section "Justification du choix technologique".


[A2] RFC 3411 — Architecture for Describing SNMP Management Frameworks

Type : Standard IETF (STD 62)
Auteurs : Harrington, Presuhn, Wijnen
Année : 2002
Lien : https://datatracker.ietf.org/doc/html/rfc3411
Résumé : Ce RFC définit l'architecture complète de SNMPv3, notamment le nouveau format de message, la sécurité des messages, le contrôle d'accès, et la configuration distante des paramètres SNMP. IETF
Utilité TFC : Base du Chapitre I sur l'architecture Manager/Agent/MIB.


[A3] RFC 3414 — User-Based Security Model (USM) for SNMPv3

Type : Standard IETF (STD 62)
Auteurs : Blumenthal, Wijnen
Année : 2002
Lien : https://datatracker.ietf.org/doc/html/rfc3414
Résumé : Ce RFC décrit le modèle de sécurité basé sur l'utilisateur (USM) pour SNMPv3, incluant les mécanismes d'authentification et de confidentialité qui constituent le cœur de la sécurité de SNMPv3. Snmp
Utilité TFC : Section "SNMPv3 sécurité / Modèle USM / authPriv" du Chapitre I. Explique précisément SHA et AES que ton matériel Ubiquiti utilise.


[A4] RFC 3415 — View-Based Access Control Model (VACM) for SNMP

Type : Standard IETF (STD 62)
Auteurs : Wijnen, Presuhn, McCloghrie
Année : 2002
Lien : https://datatracker.ietf.org/doc/html/rfc3415
Résumé : Définit le modèle VACM qui contrôle l'accès aux OIDs selon des vues. Permet de restreindre ce que chaque utilisateur SNMP peut lire ou modifier.
Utilité TFC : Section "Contrôle d'accès / bonnes pratiques" du Chapitre I et sécurisation dans le Chapitre III.


[A5] RFC 3826 — AES Cipher Algorithm in SNMPv3 USM

Type : Norme IETF
Année : 2004
Lien : https://datatracker.ietf.org/doc/html/rfc3826
Résumé : Spécifie l'utilisation d'AES comme algorithme de chiffrement dans le modèle USM de SNMPv3, remplaçant DES jugé insuffisant.
Utilité TFC : Justifie l'usage d'AES-128 sur les équipements Ubiquiti. Référence clé pour la section sécurité.


[A6] "The Practice of Network Security Monitoring" — Bejtlich, R.

Type : Livre académique
Éditeur : No Starch Press, 2013. ISBN : 978-1593275099
Résumé : Cet ouvrage de référence soutient que la sécurité réseau ne se limite pas à la construction de murs impénétrables. Il intègre la surveillance de la sécurité réseau (NSM) comme stratégie centrale, à travers la collecte et l'analyse de données pour détecter et répondre aux intrusions. Barnes & Noble
Utilité TFC : Fondement théorique pour la détection et la réponse aux incidents. Citable dans l'introduction générale et le Chapitre I.


[A7] "The Critical Role of SNMP in Enabling Network Security" — Preprint

Type : Article de revue (preprint, MDPI Preprints)
Année : 2023
Lien : https://www.preprints.org/manuscript/202310.0512
Résumé : Cet article de synthèse analyse l'utilisation des données SNMP pour développer des solutions de sécurité réseau pilotées par l'IA et le machine learning. Il examine le potentiel de SNMP pour les systèmes de détection d'intrusion, les analyses de sécurité, et la surveillance en temps réel, tout en soulignant les vulnérabilités persistantes des versions SNMP v1/v2c dues aux chaînes de communauté par défaut. Preprints.org
Utilité TFC : État de l'art sur SNMP + sécurité. Appuie la justification du choix de SNMPv3.


[A8] "Formal Security Analysis of Authentication in SNMPv3" — IEEE

Type : Article de conférence IEEE
Lien : https://ieeexplore.ieee.org/document/6483143/
Résumé : Cet article propose une vérification formelle et automatisée du protocole SNMPv3 en utilisant le vérificateur ProVerif. Il modélise les trois mécanismes de sécurité de SNMPv3 (authentification, chiffrement, contrôle d'accès) via le pi-calcul appliqué et prouve l'authenticité du protocole. IEEE Xplore
Utilité TFC : Renforce la crédibilité scientifique du choix SNMPv3 dans le Chapitre I.

⚠️ 4. POINTS D'ATTENTION SPÉCIFIQUES À TON TFC

Contrainte Ubiquiti critique : Les switches USW Pro ne supportent pas le SNMP SET (écriture). Cela signifie que la remédiation via SNMP pur (couper un port via ifAdminStatus SET) peut être bloquée sur le matériel réel. Dans EVE-NG avec Cisco IOS, le SET SNMP fonctionne. Tu devras documenter cet écart et envisager une remédiation via l'API UniFi comme alternative ou complément dans les perspectives.
